## 📖 Sobre
Este projeto foi criado para praticar conceitos do ecossistema **Node.js**: servidor HTTP, roteamento, middlewares, modularização e boas práticas de organização de código. É um repositório para aprendizado e prototipagem.

## ⚙️ Funcionalidades
- Servidor HTTP com Express
- Rotas organizadas em módulos
- Middleware de tratamento de erros
- Logging básico de requisições
- Configuração via variáveis de ambiente

## 🚀 Tecnologias
- Node.js
- Express
- dotenv (variáveis de ambiente)
- nodemon (desenvolvimento)

## 💻 Como rodar localmente
Clone o repositório, instale dependências e execute o projeto:

    git clone https://github.com/Andre-StudioNerd/Projeto_Nodejs.git
    cd Projeto_Nodejs
    npm install
    npm run dev   # modo desenvolvimento (se nodemon estiver configurado)
    npm start     # modo produção
